# 甲子園予想（koshien-yosou）

夏の甲子園の勝敗をポイント制で予想して競うローカルアプリ。**金銭・賞品のやり取りは一切なし**（賭博ではない娯楽アプリ）。

## 起動

```
npm install
npm start
```

→ http://localhost:3310 をブラウザで開く。

## 遊び方

1. 右上でニックネームを入力して「参加」（**初期持ち点 1000pt**）。
2. **試合予想**タブには全大会の「今日以降の試合」が並ぶ（ブロック・都道府県で絞り込み可）。勝つと思う学校を**タップするたび +10pt**（1試合最大100pt、締切前は取消・張り替え自由）。🤖 のAI予想は参考表示。
3. オッズは**ポイント量加重**（プール金額比）でベットのたびにリアルタイム変動（▲▼表示）、締切時点で確定。的中で ベット額 × オッズ（上限3.0倍）を獲得。
4. **長期（優勝）**タブで大会ごとの優勝校にベット（**1ベット原則100pt**、的中で100pt×オッズ・上限5.0倍）。レイト参加は1ラウンド消化ごとに参加コスト+100pt（増額分は払戻対象外）。締切は決勝開始まで。地方大会の優勝予想＝甲子園出場校の予想。
5. 試合が終わったら**管理**タブで結果を入力 → 払い戻しとランキング（**確定収支順**）に反映。持ち点が10pt未満になったら救済チップ +100pt（受領回数はランキングに表示）。AI予想の登録も管理APIから（`/api/admin/ai`）。

## データ

- `koshien.db`（SQLite）。初回起動時に**架空の49校**と1回戦17試合を自動投入。
- 本大会の組み合わせ確定後に実データへ差し替え予定（plan.md M4）。
- リセットしたいときはサーバを止めて `koshien.db` を削除 → 再起動。

詳細設計は [plan.md](plan.md) を参照。

## 注意事項

- 本アプリは**金銭・賞品を一切扱わないポイント制の予想ゲーム**です。現金・電子マネー・景品等との交換機能はなく、実装する予定もありません。賭博目的での改変・利用はしないでください。
- オッズ・AI予想は参加者内の娯楽のための参考表示です。実在の学校・選手を評価するものではなく、個人（選手）を対象とした予想項目は設計上実装しません。
- 試合データは公開報道（高野連公式サイト・各報道機関）をもとに手動入力しています。
