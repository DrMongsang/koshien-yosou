# 甲子園予想（koshien-yosou）

夏の甲子園の勝敗をポイント制で予想して競うローカルアプリ。**金銭・賞品のやり取りは一切なし**（賭博ではない娯楽アプリ）。

## 起動

```
npm install
npm start
```

→ http://localhost:3310 をブラウザで開く。

## 遊び方（2026夏・優勝予想ポット制）

1. はじめての人は「なまえ＋好きなパスワード」で**新規参加**（初期持ち点 **10,000pt**）。2回目からは同じなまえとパスワードでログイン。自分のベットは自分だけが操作できます。
2. **優勝予想（メインゲーム）**: 優勝すると思う学校をタップ（**1口5,000pt・1人2口まで**、別々の学校。もう一度タップで取消）。**全員の予想が出揃うまでお互いのピックは非公開**で、管理者の「公開」後は変更不可。
3. 大会終了時、**最も勝ち進んだ学校を持っていた人がポット（全口の合計）を総どり**（優勝 > 準優勝 > ベスト4 > … で比較。同着は山分け・端数切捨）。
4. **トーナメント表／日程・結果**タブで進行を観戦（試合単位のベットは休止中）。**チャット**タブで雑談・煽り合いも。
5. 結果入力・予想の公開（合図）・試合追加は**管理**タブ（`config.json` の管理者パスワード、または `admin_user` の名前でログイン）。AI分析（優勝確率・予想到達・理由・仮説）は管理者だけに表示。

## データ

- `koshien.db`（SQLite）。2026年夏の甲子園（代表49校・全日程）の実データ入り。
- リセットしたいときはサーバを止めて `koshien.db` を削除 → 再起動（ただしユーザー・ベットも消えるので注意）。

詳細設計は [plan.md](plan.md) を参照。

## 注意事項

- 本アプリは**金銭・賞品を一切扱わないポイント制の予想ゲーム**です。現金・電子マネー・景品等との交換機能はなく、実装する予定もありません。賭博目的での改変・利用はしないでください。
- オッズ・AI予想は参加者内の娯楽のための参考表示です。実在の学校・選手を評価するものではなく、個人（選手）を対象とした予想項目は設計上実装しません。
- 試合データは公開報道（高野連公式サイト・各報道機関）をもとに手動入力しています。
